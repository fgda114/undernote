## 먼저, 이게 무슨 문서인가

원이 이런 걸 하고 싶다고 했습니다:

> *"음악이 유행하는 건 특정 앨범으로부터 비롯되기에, 그걸 선도한 앨범, 또는
> 현상에 따라가는 앨범을 나열해야 해요.
> ex: 최근 들어 트랜지션을 시도하는 힙합 앨범: dopamine, halfblood /
> 시도하는 아티스트: 프리티펀, 슬레이어 등등"*

이걸 **사이트에서 어떻게 보여줄지**, 화면 그림 3개를 그렸습니다.
말로 설명하는 대신 그림으로 보여드리는 겁니다. **셋 중 마음에 드는 걸 골라 주세요.**

미리 알아둘 것 두 가지:

1. **어느 걸 골라도 원이 글 쓰는 방식은 똑같습니다.** 글을 쓰고, 글에 나오는
   앨범 이름들을 적어 주고, 그중 "이게 시작이었다" 하는 앨범만 표시해 주면
   끝입니다. 화면에 어떻게 보이느냐만 달라집니다.
2. **A → B → C 순서로 만들기가 어려워집니다.** A는 지금 바로 만들 수 있고,
   B는 다음 단계, C는 글이 많이 쌓인 뒤의 얘기입니다. 셋은 서로 배타적이지
   않아서, **A로 시작하고 나중에 B나 C를 얹을 수도 있습니다.**

> 아래 그림의 점수·날짜·설명 문장은 전부 **예시**입니다. 원이 든 이름
> (dopamine · halfblood · 프리티펀 · 슬레이어)을 그대로 넣어 그렸습니다.

## 안 A — "글이 곧 계보" (글 + 앨범 줄세우기)

음악 이야기 글 한 편을 쓰면, 글에 나온 앨범들이 **글 아래에 자동으로
정리되어 붙습니다.** "이 흐름을 연 앨범"과 "이 흐름 위에 있는 앨범"
두 줄로 나뉘어서요.

```
┌─────────────────────────────────────────────────┐
│  음악 이야기                                      │
│                                                 │
│  요즘 힙합은 왜 다 '트랜지션'을 할까              │
│  ─────────────────────────────────              │
│                                                 │
│  (본문) 곡과 곡 사이가 뚝 끊기지 않고 물 흐르듯    │
│  이어지는 앨범들이 부쩍 늘었다. 이 흐름이 어디서   │
│  시작됐는지 거슬러 올라가면 두 장의 앨범이 나온다. │
│  …… (원이 쓴 글이 그대로 이어짐) ……              │
│                                                 │
│  ═══════════════════════════════════════════    │
│  이 글에 나온 앨범들                              │
│                                                 │
│  ◆ 이 흐름을 연 앨범                             │
│  ┌───────────────┐  ┌───────────────┐          │
│  │ [커버]         │  │ [커버]         │          │
│  │ dopamine       │  │ halfblood     │          │
│  │ 프리티펀        │  │ 슬레이어       │          │
│  │ → 평론 읽기     │  │ → 평론 읽기    │          │
│  └───────────────┘  └───────────────┘          │
│                                                 │
│  ◇ 이 흐름 위에 있는 앨범                         │
│  ┌───────────────┐  ┌───────────────┐          │
│  │ [커버]         │  │ [커버]         │          │
│  │ (앨범 C)       │  │ (앨범 D)       │          │
│  │ (아티스트)      │  │ (아티스트)     │          │
│  │ → 평론 읽기     │  │ (평론 없음 —   │          │
│  └───────────────┘  │  이름만 표시)   │          │
│                     └───────────────┘          │
└─────────────────────────────────────────────────┘
```

- 평론을 이미 쓴 앨범은 카드에서 바로 그 평론으로 넘어갑니다.
  아직 평론이 없는 앨범은 이름만 보입니다 (가짜 링크를 만들지 않습니다).
- 반대 방향도 자동입니다: dopamine 평론 페이지에 *"이 앨범이 등장하는
  이야기: 요즘 힙합은 왜 다 '트랜지션'을 할까"* 가 자동으로 붙습니다.

**좋은 점:** 지금 바로 만들 수 있고, 원은 지금처럼 글만 쓰면 됩니다.
글이 중심이라는 사이트 성격과도 제일 잘 맞습니다.
**아쉬운 점:** "흐름이 한눈에 보인다"는 느낌은 약합니다. 읽어야 보입니다.

**만들 수 있는 시기: 지금 (1차 오픈에 포함 가능)**

## 안 B — "흐름 한 장" (시간순 그림 카드)

글 안에(또는 글 맨 위에) **가로로 흐르는 그림 한 장**이 들어갑니다.
왼쪽이 시작, 오른쪽이 지금. 누가 열었고 누가 따라오는지가 한눈에 보입니다.

```
┌──────────────────────────────────────────────────────┐
│  힙합 트랜지션의 흐름                    2025 ─→ 2026  │
│                                                      │
│   시작                          지금                  │
│   ┌────────┐                                         │
│   │ [커버]  │──┬──→ ┌────────┐                       │
│   │dopamine │  │    │ [커버]  │   ┌────────┐         │
│   │프리티펀  │  │    │ (앨범C) │──→│ [커버]  │         │
│   └────────┘  │    └────────┘   │ (앨범D) │         │
│   ┌────────┐  │                 └────────┘         │
│   │ [커버]  │──┘                                     │
│   │halfblood│      ● 커버를 누르면 평론으로            │
│   │슬레이어  │                                        │
│   └────────┘                                         │
└──────────────────────────────────────────────────────┘
```

- 이 그림 아래로 원의 글이 이어집니다. 그림은 글의 요약판 역할입니다.
- 이 그림은 **그대로 이미지로 저장해 인스타에 올릴 수 있는 모양**으로
  만듭니다. 글 링크를 공유할 때도 이 그림이 카드로 뜨게 할 수 있습니다.

**좋은 점:** "누가 시작했고 누가 따라왔나"가 말 그대로 그림이 됩니다.
SNS에 올리기 좋은 한 장이 글마다 생깁니다.
**아쉬운 점:** 앨범이 3~4개뿐인 흐름은 그림이 좀 허전합니다. 만드는
공수도 A보다 큽니다.

**만들 수 있는 시기: 다음 단계 (1차 오픈 뒤, 이야기 글이 몇 편 나온 뒤)**

## 안 C — "장르 지도" (쌓일수록 커지는 지도 페이지)

글마다 만드는 게 아니라, **사이트에 지도 페이지가 하나 있습니다.**
평론과 이야기가 쌓일수록 지도가 저절로 자랍니다. "요즘 힙합에 무슨
일이 벌어지고 있나"를 이 페이지 하나가 보여주게 됩니다.

```
┌──────────────────────────────────────────────────────┐
│  지도 — 지금 음악에서 벌어지고 있는 일                   │
│                                                      │
│    [ 트랜지션 ]              [ (다른 유행) ]           │
│   dopamine ●──●──●          ●──●                     │
│   halfblood ●─┘             │                        │
│               │             ●                        │
│    [ (장르의 뿌리) ]                                   │
│   ●───●───●───→ 지금                                  │
│                                                      │
│   ● 하나하나가 앨범. 누르면 평론이나 이야기로 이동       │
│   유행 이름을 누르면 그 흐름을 다룬 글로 이동            │
└──────────────────────────────────────────────────────┘
```

**좋은 점:** 시간이 지날수록 **이 사이트에만 있는 지도**가 됩니다.
다른 데서 볼 수 없는 것이 됩니다.
**아쉬운 점:** 글이 몇십 편은 쌓여야 지도답게 보입니다. 지금 만들면
점 몇 개 찍힌 빈 지도라서, 오히려 사이트가 비어 보입니다.

**만들 수 있는 시기: 나중 (글이 충분히 쌓인 뒤 — 내년 이후 감각)**
