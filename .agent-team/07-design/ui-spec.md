## 0. 트리트먼트 판정과 두 톤의 시각 문법

**트리트먼트: 편집(editorial).** 글이 제품이다 (charter §5). 대담함은
**타이포그래피 한 곳**에 쓰고 나머지(색·모션·장식)는 조용히 둔다.

**아이덴티티 개념 — "잉크와 낙관(落款)".** 1인 편집 매체의 권위는 필자의
서명에서 나온다 (charter §5 "리스트는 편집자의 선언"). 유일한 악센트
`--seal`(#B23A2F)은 **원의 편집 판단이 나타나는 자리에만** 쓴다: 평결 점수,
보드 순위 1위, 노미네이트 배지, 형식 오버라인. 그 외 지면은 잉크와 종이다.

**두 형식의 톤 분리 (charter §4) — 색이 아니라 활자로 가른다:**

| | 평론 (전문적·신뢰적) | 음악 이야기 (대중적·친숙) | 아티스트 소개 |
|---|---|---|---|
| 헤드라인 | **세리프** (`--serif`, 700) | 산세리프 (`--sans`, 800) | 산세리프 |
| 본문 | **세리프** 17px/1.8 | 산세리프 17px/1.75 | 산세리프 |
| 오버라인 라벨 | `평론` (seal색) | `음악 이야기` (seal색) | `아티스트` |
| 문단 밀도 | 조밀 — 논증의 호흡 | 여유 — 인용·카드 블록 허용 | 중간 |

색·악센트·레이아웃 골격은 공유한다 — **구분되되 단절되지 않는다.**
사다리 링크(§2.6)를 타고 넘어갈 때 "같은 사이트의 다른 방"으로 느껴져야 한다.
근거: charter §4 이해의 사다리 — 두 형식을 다른 사이트처럼 만들면 이동이 끊긴다.

**전 지면 클라이언트 JS 0** (James 합의). 인터랙션은 `:hover`/`:focus-visible`
/anchor 만으로 성립한다.

## 1. 홈 `/` — 노미네이트 현황판 (D5)

### 1.1 레이아웃 (일반 상태: 평론 6편 이상)

```
[마스트헤드]  undernote·           평론  이야기  올해의앨범  아카이브  소개
──────────────────────────────────────────────────────────────
[보드 패널 — 지면의 얼굴]
  오버라인(seal): 2026 올해의 앨범
  H1(세리프): 현재 노미네이트
  캡션(muted): 평론이 쌓일 때마다 바뀝니다 · 12월에 확정됩니다 · {날짜} 기준
  ┌─ 버킷 컬럼 그리드 (데스크톱: 버킷 수만큼 1~3열, 모바일 1열) ─┐
  │ 힙합/R&B          팝                록                       │
  │ 1 ▐커버▌ 앨범명   1 ▐▌ …           (빈 버킷 상태 §1.4)      │
  │   아티스트   8.7  …                                          │
  │ 2 … (최대 5행)                                               │
  └──────────────────────────────────────────────────────────────┘
  [올해의 앨범 전체 보기 →]  (/list/2026/)
──────────────────────────────────────────────────────────────
[최신 글]  H2: 최신 글
  글 카드 목록 (최신 8개, 유형 혼합) — 점수 비표시 (D2 탐색 지면)
  각 카드: 형식 라벨 · 제목 · 앨범/아티스트 or 요지 1줄 · 날짜
──────────────────────────────────────────────────────────────
[푸터]  소개/기준 · 아카이브 · © — SNS 링크(원 인스타/유튜브)
```

### 1.2 보드 행 (BoardRow 컴포넌트 — components.md)
- `순위(tabular) · 커버 48px · 앨범명(700)/아티스트(muted) · 점수(tabular, 우측)`
- 행 전체가 평론 링크 (US-2 AC1 — 클릭 1회). 1위 행: 순위 숫자 `--seal`,
  좌측 2px seal 보더. 2~5위는 잉크.
- 점수는 소수 1자리 고정 표기 "8.7" (SS-3).

### 1.3 상태 — 버킷별 (US-2 AC2)
| 상태 | 처리 |
|---|---|
| 5행 만석 | 기본형 |
| 1~4행 | 있는 만큼만. **빈 행·자리표시 금지** (가짜 채움 금지) |
| 0행 | §1.4 빈 버킷 |
| 교체 발생 후 | 별도 표시 없음 (이력 연출은 1차 비범위 — 보드는 항상 현재형) |

### 1.4 빈 버킷 상태
버킷 라벨 + 1줄: `아직 이 장르의 후보가 없습니다.` (muted, 15px) —
사과·장식 없음. 버킷 자체를 숨기지 않는다 (연간 구조가 보이는 것이 D5의 목적).

### 1.5 극초기 변형 (전체 평론 0~5편 — usp.md CONCERNS "1년차 공백")
- 보드 패널을 **진행 배너**로 축소: 오버라인 + 1줄
  `올해의 앨범 후보가 여기서 자랍니다 — 지금까지 평론 {n}편` + 전체 보기 링크.
- 지면의 얼굴은 **최신 평론 히어로**로 교체: 커버(320px) + 세리프 헤드라인 +
  발췌 2줄. 이하 최신 글 목록.
- 전환 규칙(구현 조건): 노미네이트 총수 ≥6이면 일반형, 미만이면 극초기형.
  (수치는 시안값 — Andrew가 하드코딩하지 말고 설정으로)
- 평론 0편(공개 직전): 히어로 자리에 소개/기준 요지 + `첫 평론을 준비하고
  있습니다.` 1줄.

### 1.6 확정 직후 변형 (12월~이듬해 초, SS-6)
보드 패널이 `2026 올해의 앨범 — 확정` 링크 카드(서문 첫 문장 발췌)로 바뀌고,
그 아래 새해 빈 보드(§1.4 상태 × 전 버킷)가 온다. "확정 리스트 + 새해 빈
보드"의 공존이 연중 진행형 서사를 유지한다.

## 2. 평론 `/reviews/{slug}/` (CF-1 · D2)

### 2.1 히어로 — 점수 없음 (D2 확정)
```
오버라인(seal): 평론
H1(세리프 34px/1.35, balance): {앨범명}
서브(sans 17px muted): {아티스트} · {버킷 라벨} · {발매일}
커버: 320px, 우측 배치(데스크톱 2컬럼) / 상단(모바일)
```
- 히어로 필드는 James 계약의 4개(앨범·아티스트·장르·발매일)뿐.
  **점수·배지 금지** — 논증 전에 판결을 누설하지 않는다.
- 아티스트명 → `/artists/{slug}/` 링크 (US-9 AC1).

### 2.2 본문 — 읽기 경험 (성패 지점, charter §4)
- 컬럼 660px(≈열람폭 38자) 중앙. 세리프 17px, line-height 1.8,
  문단 간격 `--s-24`. 모바일 좌우 패딩 20px.
- 헤드라인·인용부만 위계 장치. 본문 내 링크는 seal 밑줄
  (`text-underline-offset:3px`).
- 광고·사이드바·추천 위젯 없음 — 본문 옆은 여백이다.

### 2.3 평결 블록 (ScoreVerdict — 매직 모먼트)
본문 종료 직후:
```
── seal 2px 단축 룰(48px) ──
오버라인: 평결
[세리프 42px]  8.3  [/10 — 15px muted]
{현재 노미네이트일 때} 배지: ● 지금 힙합/R&B 노미네이트 2위 → 보드 보기
듣기: [Apple Music ↗] [Spotify ↗] …(있는 것만, SS-13)
```
- 배지를 히어로가 아닌 **여기** 두는 이유: 배지는 점수의 파생물이다(SS-4).
  상단 배치는 D2 "점수는 결론"을 우회 누설한다. 배지 링크는 D6-3의
  역방향(평론→보드)을 겸한다.
- 듣기 링크 0개 → 듣기 행 미표시 (빈 껍데기 금지). 배지 없음 → 배지 행 미표시.

### 2.4 커버 상태 (SS-14)
| 상태 | 처리 |
|---|---|
| 커버 있음 | WebP+폴백, `--r-4`, 지연 로드 |
| 커버 없음 | 플레이스홀더: `--ink` 바탕 + 앨범명 첫 글자(세리프, `--paper`) — lineage-concepts.html의 자리표시와 동일 문법 |

### 2.5 자동 부속 (평결 블록 아래, 순서 고정)
1. **"이 앨범이 등장하는 이야기"** (§2.6)
2. **"{아티스트}의 다른 글"** — 있을 때만 (James 계약 필드)

### 2.6 사다리 블록 (LadderBlock — US-3)
- 형식: `--wash` 바탕 카드, **산세리프**(이야기의 목소리로 초대), 이야기
  제목 + 1줄 발췌, seal 화살표.
- 리드 카피: `이 점수가 낯설다면 — 이 앨범이 놓인 흐름 이야기` (직접 참조 시)
  / `이 장르가 낯설다면 — {버킷} 이야기` (장르 폴백, US-3 AC2)
- 상태: 직접 참조 ≥1 → 전부(발행 역순) / 0 → 장르 폴백 1~2편 / 폴백도 0 →
  **블록 미출력** (US-3 AC3).

## 3. 음악 이야기 `/stories/{slug}/` (CF-5)

- 헤드/본문 산세리프 (§0 톤 문법). 컬럼 660px, 본문 17px/1.75.
- 본문 내 앨범 언급: 평론 있으면 seal 밑줄 링크 (US-4 AC1), 없으면
  플레인 텍스트 (US-4 AC2 — 유사 링크 스타일 금지).
- **말미 앨범 상자 (AlbumBox — 계보 안 A, 기본 확정):**
  `lineage-concepts.html` 안 A와 동일 — 상단 2px 잉크 룰, "이 글에 나온 앨범",
  행: 커버 44px · 앨범명/아티스트·연도 · 우측 `평론 읽기 →`(있을 때) /
  `평론 준비 중`(muted, 링크 아님).
  참조 0개 → 상자 미출력.
- **원이 안 B 선택 시:** AlbumBox 위에 LineageBlock(components.md 예비 계약)
  삽입 — role 태그 있는 글에서만 렌더, 없으면 자동 폴백으로 안 A만.

## 4. 연간 리스트 `/list/{year}/` (CF-2·3)

### 4.1 진행형 (연중)
```
오버라인: 2026 올해의 앨범   H1(세리프): 진행 중인 한 해
캡션: 이 리스트는 평론이 쌓일 때마다 바뀝니다. 12월에 확정됩니다.
[섹션 1] 올해의 앨범 후보 — 현재 상위 10 (SS-5, 점수순, 전 항목 평론 링크)
[섹션 2] 장르별 노미네이트 — 버킷별 보드 (홈과 동일 BoardRow, 5행 상한)
[꼬리] 지난해 확정 리스트 링크 (있으면)
```
- 리스트 행: `순위 · 커버 64px · 앨범명(세리프 700)/아티스트 · 점수` —
  점수 표시+정렬 (D2 리스트 지면). 순위=점수순 불일치는 빌드가 막는다 (SS-8).

### 4.2 확정형 (SS-6 전환 후, 동일 URL)
- 오버라인이 `확정`으로, 캡션이 `{확정일}에 확정된 리스트입니다.
  이후의 평론·점수 수정은 여기 반영되지 않습니다.`로 바뀐다.
- **서문(원의 글)이 리스트 위에 온다** (US-1 AC3) — 세리프 본문, §2.2 규격.
- 1위(올해의 앨범)는 커버 160px 대형 행. 버킷별 선정 1은 buckets 섹션
  상단에 seal 보더로 구분.
- 2편 이하 버킷: 섹션 미출력 (US-13 AC3) — "미달" 문구도 없음 (사과 금지).

## 5. 월말정산 `/list/{year}/{mm}/` (CF-4)

- H1(세리프): `{m}월의 앨범` · 캡션: `{m}월에 발행된 평론 {n}편, 점수순.`
- 행 규격은 연간 리스트와 동일 (점수 표시). 전 항목 평론 링크 (US-5 AC1).
- 평론 0편인 달: **페이지·목록 항목 자체가 없음** (US-5 AC2). 월 목록은
  `/archive/` 연도 축 하위에 존재하는 달만 나열.
- 이 지면이 커뮤니티 유통의 단위다 — OG 카드(§11)에 그 달 1~3위 요약.

## 6. 아카이브 `/archive/…` (CF-7)

- 진입: 3축 탭형 목록 — `연도 / 장르 / 아티스트` (+ 상단에 유형 필터
  프리셋: 평론·이야기 — 내비 "평론/이야기"가 여기로 온다).
- 목록 행: `형식 라벨 · 제목 · 아티스트/요지 · 날짜` — **점수 필드 자체가
  템플릿에 없음** (James 데이터 계약, US-6 AC2).
- 빈 축 값(예: 글 0편인 연도)은 목록에 나타나지 않는다.

## 7. 아티스트 `/artists/{slug}/` (CF-6)

- 헤드: 아티스트명(세리프 27px). 소개글 있으면 산세리프 본문 (§0).
- 집계 섹션: `{이름}을 다룬 글` — 아카이브 행 규격 (점수 비표시).
- 소개글 없음 → 집계만, 빈 소개 영역 미표시 (US-9 AC2).

## 8. 소개/기준 `/about/` (CF-8 · US-8)

세리프 본문 지면. 필수 3문(US-8 AC1)을 소제목으로 구조화:
1. `여기 실린 앨범은 전부 "안 들으면 손해" 문턱을 통과한 것입니다.`
2. `다루지 않았다는 것은, 아직 추천하지 않는다는 뜻입니다.`
3. `점수는 들을까 말까가 아니라, 이미 검증된 것들 사이의 순위입니다.` (usp.md §3-3 카피 요구 승계)
콘텐츠 본문은 원+리드 협의 (E5) — 디자인은 틀과 위 핵심 문장 위치만 고정.

## 9. 404

세리프 1줄 `이 주소에는 글이 없습니다.` + 홈·아카이브 링크 2개. 장식 없음.

## 11. OG/공유 카드 (SS-15 연동 — 유입의 실체, charter §3)

규격 1200×630 1종, 빌드 생성. 배경 `--paper`, 잉크 타이포, seal 포인트 1개.

| 유형 | 구성 | 규칙 |
