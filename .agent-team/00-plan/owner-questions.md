# 음악 사이트 — 구상 질문지

원님께.

말로 정리하기 어렵다고 하셔서, **고르기만 하면 되는 형태**로 만들었습니다.
빈칸을 채우는 게 아니라 "이건 맞고 저건 아니다"만 골라 주셔도 충분합니다.

- **전부 답 안 하셔도 됩니다.** 모르겠는 건 "모르겠음"이라고 쓰거나 그냥 넘기세요.
- 한 번에 다 하실 필요 없습니다. 1번만 답하고 나머지는 나중에 하셔도 돼요.
- **정답이 없습니다.** 지금 정한 것도 나중에 바꿀 수 있습니다.

---

## 1. 뭘 제일 하고 싶으세요

말씀하신 세 가지입니다. **순서를 매겨 주세요** (1=제일 하고 싶은 것).

```
[  ] 평론 — 앨범 듣고 평가하는 글
[  ] 아티스트 소개 — 이 사람 누구다, 어떤 음악 한다
[  ] 음악 이야기 — "요즘 음악은 왜 짧아지는가" 같은 글
```

**그리고:** 셋 중에 **없어도 되는 것**이 있나요? 있으면 뭔가요?

> 왜 묻냐면 — 셋 다 잘하려면 시간이 세 배 듭니다. 하나가 중심이고
> 나머지가 곁다리인 편이 오래 갑니다.

---

## 2. 점수 이야기

앨범에 점수 매기고 싶다고 하셨는데, 좀 더 구체적으로요.

**2-1. 어떤 형태가 좋으세요?**
```
[ ] 10점 만점 (8.4 이런 식으로)
[ ] 5점 만점 / 별 5개
[ ] 좋음 / 보통 / 별로 같은 단순한 등급
[ ] 점수 없이 글만
[ ] 잘 모르겠음
```

**2-2. 점수 없이 글만 있으면 어떨 것 같으세요?**
(별로다 / 상관없다 / 그건 좀 아쉽다 — 느낌만 말씀해 주셔도 됩니다)

**2-3. 남의 점수를 볼 때, 점수만 보고 넘어가시나요 아니면 글을 읽으시나요?**

> 왜 묻냐면 — 점수를 매기면 사람들이 **글을 안 읽고 점수만 봅니다.**
> 그게 괜찮은지, 아니면 글을 읽게 하고 싶은지가 사이트 구조를 완전히 바꿉니다.

---

## 3. 어떤 앨범을 다루실 건가요

**3-1. 주로 다룰 앨범은?**
```
[ ] 새로 나온 앨범 위주
[ ] 옛날 앨범도 상관없음
[ ] 옛날 앨범 위주
[ ] 안 유명한 앨범 위주
[ ] 그냥 내가 그때그때 듣고 싶은 거
```

**3-2. 신보 위주로 가면 이런 게 따라옵니다. 괜찮으세요?**
- 앨범이 나오는 시점에 맞춰 써야 합니다 (마감이 생김)
- 안 쓰고 넘어간 주가 생기면 티가 납니다
- 대신 사람들이 검색해서 들어오기 쉽습니다

```
[ ] 괜찮음, 그게 오히려 리듬이 됨
[ ] 부담됨. 마감 없는 게 나음
[ ] 잘 모르겠음
```

---

## 4. 여기가 제일 중요합니다 — "특별한 무언가" 찾기

"이런 거 다 있어"라고 하셨죠. 맞습니다. 그래서 **직접 아이디어를 떠올리는 대신**,
질문에 답하다 보면 나오게 해봤습니다. 편하게 답해 주세요.

**4-1. 최근에 읽고 "이거 좋다" 했던 음악 글이 있나요?**
뭐였고, 뭐가 좋았나요? (유튜브 영상이나 커뮤니티 글도 괜찮습니다)

**4-2. 반대로, 음악 매체 보면서 "이건 좀 별로다" 싶었던 적은요?**
뭐가 별로였나요?

> 이게 제일 중요한 질문일 수 있습니다. **싫은 걸 말하는 게 좋은 걸
> 말하는 것보다 쉽고, 거기서 만들 것이 나옵니다.**

**4-3. 친구한테 앨범 추천할 때 뭐라고 말씀하세요?**
실제로 최근에 누구한테 뭘 추천했는지, 그때 뭐라고 했는지 그대로 적어 주세요.

> 그 말투가 이 사이트의 목소리가 됩니다.

**4-4. 이 사이트를 누가 봤으면 좋겠어요?**
"음악 좋아하는 사람" 말고, **아는 사람 한 명을 떠올려서** 말해 주세요.
(예: "○○ 같은 애들 — 음악 많이 듣는데 뭘 들을지 몰라서 맨날 같은 것만 듣는")

**4-5. dcinside 링크 보내주셨을 때 "이런 거 다 있어"라고 하셨는데,
그 글들에 **없는 것**은 뭐라고 느끼셨나요?**
(막연해도 됩니다. "뭔가 정리가 안 돼 있다" 같은 것도 답입니다)

---

## 5. 이 중에 끌리는 게 있나요

아이디어를 떠올리는 것보다 **있는 걸 고르는 게 쉽습니다.**
아래 넷 중에 "오 이건 좀" 싶은 게 있으면 표시해 주세요. 없으면 없다고 하셔도 됩니다.

**(가) 글 끝에 다음 앨범으로 가는 다리를 놓기**
리뷰 끝에 "이 앨범의 이런 점이 좋았다면 → ○○ 앨범" 하고 **이유를 붙여서**
사이트 안의 다른 글로 링크를 겁니다. 알고리즘 추천이 아니라 쓴 사람이 직접 잇는 것.
```
[ ] 끌림   [ ] 별로   [ ] 무슨 말인지 모르겠음
```

> 아까 "비슷한 음악 알고리즘으로 나오는 거 이런 거 다 있어"라고 하셨고,
> 노래 찾기 기능은 "안 어울린다"고 하셨죠. 이건 기능이 아니라 **글로 푸는 방식**이라
> 매거진에 안 어긋납니다. 그래서 넣어봤습니다.

**(나) 유명한 앨범은 "다시 듣기"로만 다루기**
다들 아는 명반을 쓸 때, 아는 얘기는 첫 문단에서 끝내고 **그다음부터** 씁니다.
"이 앨범 좋죠" 말고 "근데 다들 이 부분은 안 말하더라".
```
[ ] 끌림   [ ] 별로   [ ] 무슨 말인지 모르겠음
```

**(다) "음악 이야기"가 중심이고 리뷰가 그 근거가 되는 구조**
"요즘 음악은 왜 짧아지는가" 같은 글을 쓰고, 그 안에서 개별 앨범 리뷰들로 링크를 겁니다.
에세이가 큰 줄기, 리뷰가 가지.
```
[ ] 끌림   [ ] 별로   [ ] 무슨 말인지 모르겠음
```

**(라) 한국어로 아무도 안 쓴 앨범 위주로 쓰기**
검색해도 한국어 글이 안 나오는 앨범들. 찾는 데 품이 들지만 그 앨범에 대한
한국어 글이 여기 하나뿐이 됩니다.
```
[ ] 끌림   [ ] 별로   [ ] 무슨 말인지 모르겠음
```

**5-1. 넷 다 별로면 — 뭐가 빠진 것 같으세요?** (막연해도 좋습니다)

## 6. 현실적인 것들

**6-1. 글을 얼마나 자주 쓸 수 있을 것 같으세요?**
```
[ ] 주 2~3편   [ ] 주 1편   [ ] 2주에 1편
[ ] 한 달에 1~2편   [ ] 모르겠음, 써봐야 알 듯
```
> 솔직하게 적어 주세요. 여기서 무리하면 두 달 뒤에 멈춥니다.
> 적게 잡고 지키는 게 훨씬 낫습니다.

**6-2. 글은 누가 쓰나요?**
```
[ ] 나 혼자   [ ] 나 + 몇 명 더 (몇 명?)   [ ] 아직 모름
```

**6-3. 원님이 맡고 싶은 건 어디까지인가요?**
```
[ ] 글만 쓰고 싶다
[ ] 글 + 사이트 구성(어디에 뭐가 있을지)도 같이 정하고 싶다
[ ] 다 관여하고 싶다
```

**6-4. 사이트 이름 — 지금 후보가 둘입니다. 어느 쪽이 나으세요?**
```
[ ] undernote   [ ] AFTERTRACK   [ ] 둘 다 별로 (다른 생각 있으면 적어주세요)
```
