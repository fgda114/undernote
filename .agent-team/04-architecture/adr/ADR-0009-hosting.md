# ADR-0009. 호스팅 = 정적 CDN. 최종 선택은 W5 셋업 시 무료 한도 실확인 후

## 맥락

산출물이 순수 정적 디렉토리이므로 호스팅 요건은 최소다. 무료 티어 한도·정책은
시점 민감 정보라(John도 미확인 표기) 지금 확정하면 지어낸 값이 된다.

## 결정

**요건만 확정한다:** ① 정적 파일 + CDN ② 커스텀 도메인 + HTTPS 자동 ③ git push 연동
자동 빌드·원자적 배포 ④ 월 비용 0 목표(도메인 등록비만 예외). 락인 없음 —
산출물이 표준 정적 디렉토리이므로 어느 후보로도 이전 비용 ~0.

**후보 (우선순위):** ① Cloudflare Pages ② Netlify (John 검토 권고) ③ GitHub Pages.

> ### ✅ 벤더 확정 — GitHub Pages (W5.0, 2026-09-02)
>
> 우선순위 ①이 아닌 ③을 택했다. **이탈이 아니라 위임된 결정의 실행이다** — 본 ADR은
> 요건만 확정하고 벤더 선택을 W5로 미뤘으며, 우선순위는 구속이 아닌 제안이었다.
>
> **근거 (Andrew, 3사 공식 문서 실확인 2026-09-02 — 수치·URL은 `08-impl-notes/frontend.md`):**
> 1. **검증과 배포가 같은 파이프라인 1개.** 저장소가 이미 GitHub이므로 검증 게이트를
>    통과한 **dist-1 바이트를 재빌드 없이 그대로 배포**한다. 다른 플랫폼에서 재빌드하면
>    "검증한 산출물"과 "배포된 산출물"이 달라질 수 있다 — 결정성이 제품 약속인 이
>    프로젝트에서 이 원자성은 부수 효과가 아니라 정합이다
> 2. 신규 계정·외부 연동 0. Cloudflare는 계정 연결이 User 대시보드 작업이라 현시점 착수 불가
> 3. 한도 충분 — 사이트 1GB · 대역폭 100GB/월(soft). 이 제품은 수백 페이지 규모
> 4. 요건 4종 충족: 정적+CDN · 커스텀 도메인+HTTPS 자동 · push 연동 원자 배포 · 월 0원
>
> **되돌리기 비용 ~0** — 정적 산출물이므로 다른 벤더로 옮기는 데 코드 변경이 없다.
>
> ⚠️ **제약 — 상업적 이용 금지.** GitHub Pages 약관상 상업 사이트 운영이 금지된다.
> 현재 charter §5가 유료화·결제를 비범위로 두어 충돌하지 않으나, **원이 향후 수익화를
> 원하면 이 벤더를 바꿔야 한다.** 그 시점의 전환 비용은 여전히 낮다(위 참조).
>
> **User 작업 1건 잔여:** 저장소 Settings → Pages → Source = `GitHub Actions`.
> 이 설정 전까지 deploy 잡만 실패하며 **verify 게이트는 정상 동작**한다.
셋 다 현재 무료 한도 **미확인 — W5 셋업일에 공식 문서로 확인 후 확정** (build-plan T0).

- (−) W5 시작 시 30분 내외의 확인 작업 1건 발생.
