# ADR-0008. 커버 아트 저장·표시 정책 — 인용·비평 목적 사용의 실무 범위 (과제 ④)

| | |
|---|---|
| 상태 | **Accepted (실무 판단)** — 법률 자문이 아님. 미확인 항목은 명시 |
| 작성 | James · 2026-09-01 |
| 의존 | charter §6 · task-graph 2.5 · SS-14·15 |

## 맥락

앨범 커버는 저작물이다. 이 사이트는 커버를 **비평 대상 앨범의 식별·비평 맥락 제시**를
위해 표시한다. 상업적 라이선스 계약은 1인 무수익 프로젝트 규모에서 비현실적이므로,
저작재산권 제한 규정 안에서 성립하는 사용 범위를 정의해야 한다.

## 법적 근거 (실무 이해 — 출처 명기)

- **저작권법 제28조 (공표된 저작물의 인용):** 공표된 저작물은 **보도·비평·교육·연구 등**을 위하여 **정당한 범위 안에서 공정한 관행에 합치되게** 인용할 수 있다. 출처: [국가법령정보센터](https://www.law.go.kr/LSW//lsLawLinkInfo.do?lsJoLnkSeq=900605472&lsId=000798&chrClsCd=010202&print=print) · [CaseNote 제28조](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EC%A0%80%EC%9E%91%EA%B6%8C%EB%B2%95/%EC%A0%9C28%EC%A1%B0)
- 정당한 범위·공정한 관행의 판단 요소(인용 목적, 인용 분량·방법, 주종관계 — 인용자의 저작물이 주, 피인용물이 종 — 원저작물 수요 대체 여부, 출처 명시)는 실무 해설이 공통적으로 제시한다. 출처: [찾기쉬운 생활법령정보 — 공표된 저작물의 인용](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=695&ccfNo=3&cciNo=2&cnpClsNo=2)
- 보조 근거: 제35조의5(공정이용 일반조항) · 제37조(출처의 명시) — 조문 존재는 위 법령 출처에서 확인.
- **미확인:** 앨범 커버 썸네일의 웹진 사용을 직접 다룬 국내 판례의 존부·판시 내용. 본 정책은 조문 + 공개 실무 해설 기준의 보수적 설계이며, **확정적 적법성 판단은 법률 검토 필요.**

## 결정 — 저장·표시 5원칙

1. **비평 종속 표시만.** 커버는 (a) 그 앨범의 평론 페이지, (b) 그 평론에서 도출된 리스트 지면의 항목(클릭 1회로 평론 도달 — SS-8이 보장하는 구조가 곧 비평 종속성의 구조적 증명), (c) 그 앨범을 참조하는 음악 이야기의 참조 목록에만 표시한다. **커버만 모은 갤러리성 지면은 만들지 않는다** (주종관계 붕괴).
2. **축소 해상도만 저장·서빙.** 원본 보관 없이 최장변 640px 사본만 저장, 파생 4크기(96/320/640 + OG 합성)는 전부 그 이하 (Jonnathan 합의 2026-09-01). 원본 대체 수요를 만들지 않는다.
3. **출처 명시(제37조).** 커버가 표시되는 모든 지면에 앨범명·아티스트를, 평론 페이지에는 레이블(확보 시)까지 병기. `alt` 텍스트 포함.
4. **제거 프로세스.** 권리자 요청 시 해당 커버 파일 삭제만으로 대응 종료 — 플레이스홀더 발행이 이미 정상 경로(SS-14)라 빌드·리스트가 깨지지 않는다. about 지면에 연락 경로 명시 (Jonnathan·W5 전달).
5. **OG 카드의 커버 사용 — 조건부 + 미확인 표시.** 카드 이미지에서 커버가 단독 유통되지 않도록 **커버(축소) + 앨범·아티스트 텍스트 + 매체명을 합성한 카드**만 허용한다(비평 지면으로의 안내물 성격 유지). 단 SNS 피드에서 이미지가 본문과 분리 노출되는 맥락은 사이트 내 인용보다 요건 충족이 불확실하다 — **미확인, 법률 검토 필요.** 검토 전까지는 합성 카드로 운용하되, 리스크 회피가 필요해지면 SS-15의 텍스트 기본형 카드로 전환 가능하게 템플릿을 이원화한다 (Jonnathan 합의).

## 대안

1. **커버 완전 비사용** — 법적 리스크 0이나 음악 매거진의 식별성·공유 카드 가치 훼손이 과대. 기각 (단 5의 전환 경로로 보존).
2. **외부(CAA/스트리밍) 핫링크** — 표시 주체는 동일해 법적 이득이 불분명하고, 링크 부패·성능 문제만 추가 (John 권고 위반). 기각.
3. **레이블 개별 허락 취득** — 편당 노동이 원·User 접점 상한(D7)을 초과. 기각.

## 결과

- (+) SS-14(자체 호스팅 사본·플레이스홀더)·SS-15(카드 폴백)의 설계가 법적 정책과 정합.
- (−) 커버 원본 화질 표시는 포기 — 비평 매체에 640px는 충분하다는 실무 판단.
