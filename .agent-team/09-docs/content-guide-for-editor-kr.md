# undernote — 글 낼 때 무엇을 채워야 하나요

| | |
|---|---|
| 대상 | 원(편집장 · 필자) — 개발자 아님 |
| 작성 | Timothy · 2026-09-03 |
| 원칙 | 이 문서에 나온 것 외에는 아무것도 준비하지 않아도 됩니다. 발매일·레이블·커버 이미지 같은 것은 시스템이 찾아 줍니다 |

이 사이트는 **글 + 아래 표에 적힌 몇 가지 정보**만 있으면 나머지(페이지 만들기, 리스트에
올리기, SNS 공유 카드 만들기, 관련 글끼리 링크 연결하기)는 전부 자동으로 됩니다.
User(개발 담당)에게 아래 항목만 전달하면 됩니다.

---

## 평론을 낼 때 — 딱 4가지 + 본문

| 항목 | 무엇을 적나요 | 왜 필요한가요 |
|---|---|---|
| **① 앨범/아티스트** | 어떤 앨범, 어떤 아티스트인지 | 앨범 정보(발매일 등)를 시스템이 자동으로 찾기 위해서. 이미 검색된 게 없으면 발매 연도만이라도 필요합니다(연도가 있어야 "올해의 앨범" 리스트에 들어갈 수 있어요) |
| **② 장르 묶음** | 이 앨범이 어느 장르 카테고리에 속하는지, 또는 "그 외" | "그 외"를 골라도 발행에는 전혀 문제없습니다. 다만 장르별 리스트에는 안 들어가고, 연말 총합 리스트에는 그대로 들어갑니다 |
| **③ 점수** | 10점 만점, 소수점 첫째 자리까지 (예: 8.3) | 순위를 매기는 유일한 척도입니다. 8.35처럼 소수점 둘째 자리는 쓸 수 없습니다 |
| **④ "안 들으면 손해" 체크** | 이 앨범을 실을 만하다는 최종 확인 | 이 체크가 없으면 아무리 글이 완성돼 있어도 발행되지 않습니다. "실렸다 = 추천했다"는 이 사이트의 핵심 약속입니다 |
| **본문** | 평론 글 자체 | 비어 있으면 발행되지 않습니다. 점수만 있고 글이 없는 평론은 낼 수 없습니다 |

**필요 없는 것:** 발매일·레이블·커버 이미지 — 전부 시스템이 찾아 줍니다(못 찾으면 User가 그때
알려 줄 거예요). **세부 태그**(예: "시티팝" 같은 세부 장르 표기)는 있으면 좋지만 없어도
발행에 전혀 지장 없습니다.

**주의할 점 1가지:** 한번 발행한 글의 주소(파일명)는 나중에 바꾸지 않는 게 좋습니다. SNS에
공유된 링크가 죽어버리기 때문입니다. 오타 등으로 정말 바꿔야 한다면 User에게 미리
알려주세요(리다이렉트 처리가 필요합니다).

## 음악 이야기를 낼 때 — 제목·날짜 + 언급한 앨범 목록

| 항목 | 무엇을 적나요 |
|---|---|
| **제목** | |
| **날짜** | |
| **본문** | 비어 있으면 발행되지 않습니다 |
| **언급한 앨범들** | 글에서 다룬 앨범 이름을 목록으로 알려주면, **평론이 이미 있는 앨범은 자동으로 링크가 걸립니다.** 아직 평론이 없는 앨범은 그냥 텍스트로만 나오고, 나중에 그 앨범 평론이 나오면 **다시 글을 고칠 필요 없이 자동으로 링크가 생깁니다.** |

이야기에서 앨범을 하나도 언급하지 않아도 발행은 됩니다 — 다만 평론과 서로 연결되는
"이해의 사다리" 기능에는 참여하지 않습니다.

---

## 아티스트 소개를 낼 때 — 이름 + (선택) 소개글

| 항목 | 무엇을 적나요 |
|---|---|
| **표기명** | 필수 |
| **소개글** | **선택 사항입니다.** 안 써도 됩니다 — 그 아티스트가 참여한 평론·이야기 목록만으로도 페이지가 성립합니다 |

새 아티스트가 처음 등장하면(앨범 등록 시) 시스템이 이름만 있는 빈 페이지를 자동으로
만들어 둡니다. 소개글은 나중에 원할 때 언제든 채워 넣을 수 있고, 순서는 상관없습니다.

**주의할 점:** 어떤 평론·이야기에서도 전혀 언급되지 않는 아티스트 페이지는 만들 수
없습니다(발행이 막힙니다) — 아무도 도달할 수 없는 페이지이기 때문입니다. 실수로 만든
페이지라면 삭제하면 되고, 실제 다룰 예정이라면 해당 앨범/이야기를 먼저(또는 함께)
발행하면 됩니다.

## 연말 확정(올해의 앨범 발표)

시점은 원이 정합니다 — 시스템이 강제하지 않습니다. 준비되면 **서문 한 편**만 쓰면
됩니다. 그 시점의 리스트가 그대로 얼려져서(이후 점수를 고쳐도 안 바뀝니다) "올해의
앨범" 확정 페이지로 공개되고, 다음 해 리스트는 빈 상태로 새로 시작합니다.

한 장르에서 그 해 평론이 3편이 안 되면, 그 장르는 그 해 리스트에 나오지 않습니다
(억지로 순위를 채우지 않는다는 원칙입니다). 최소 편수 기준을 바꾸고 싶으면 User에게
알려주세요(설정값 하나만 바꾸면 됩니다).

## 발행 후 바뀌는 것 / 안 바뀌는 것

| 상황 | 결과 |
|---|---|
| 평론 점수를 나중에 고침 | 평론 페이지·현재 리스트·아카이브 전부 새 점수로 바뀝니다. **단, 이미 "연말 확정"된 옛날 리스트는 절대 안 바뀝니다** |
| 두 앨범이 점수가 똑같아서 순위 경계에서 동점 | 시스템이 원에게 알려드립니다(빌드 리포트로). 기본은 먼저 실린 평론이 위, 원하시면 점수를 살짝(예: 8.5 → 8.6) 조정해서 순서를 직접 정할 수 있습니다 — 강제는 아닙니다 |
| 커버 이미지를 못 찾음 | 기본 이미지로 발행되고, 나중에 이미지를 구하면 다음 업데이트 때 자동으로 바뀝니다. 글 발행 자체는 막히지 않습니다 |
| 커버 이미지를 직접 구해서 넣을 때 | **`.jpg` 파일이어야 합니다.** PNG나 다른 형식이면 저장하기 전에 jpg로 바꿔 주세요 — 다른 형식은 시스템이 거부합니다. (파일명은 User가 정해 줍니다) |
| 듣기 링크(스트리밍)를 못 찾음 | 발행은 그대로 되고, 듣기 링크 영역만 빠집니다 |

---

## 정리 — 원이 실제로 하는 일은 이게 전부입니다

1. 평론: 글 + 앨범/아티스트 + 장르 + 점수 + "안 들으면 손해" 체크
2. 이야기: 글 + (있으면) 언급 앨범 목록
3. 아티스트 소개: 이름 + (선택) 소개글
4. 연말: 서문 한 편

나머지 — 페이지 만들기, 순위 계산, 관련 글 연결, SNS 공유 카드, 지난 글 찾아보기 —
는 전부 시스템이 합니다.
