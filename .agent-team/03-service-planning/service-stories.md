## 발행 계층

### SS-1. 발행 입력 검증 `[CF-9 · US-10]`

- **트리거:** 평론·음악 이야기·아티스트 소개의 발행 시도.
- **규칙:** 콘텐츠 유형별 필수 필드 검증 —
  평론: 본문 · 앨범명 · 아티스트 · 장르 버킷(목록 또는 "그 외") · 점수 ·
  편집 체크("안 들으면 손해인가" — USP-C 기록) /
  음악 이야기: 본문 · 참조 앨범 목록(0개 허용하되 경고) /
  아티스트 소개: 본문 · 아티스트명.
  **세부 장르 태그(옵션, 복수)**는 태그 등록부 대조로 표기 정규화 —
  미등록 표기는 경고 + 등록부 추가 제안 (D1-②).
- **예외:** 필수 필드 누락 → 발행 중단 + 누락 항목 명시 (부분 발행 없음).
  옵션 필드(세부 태그) 부재는 발행을 막지 않는다.
- **인수조건:** Given 점수 없는 평론 / When 빌드 / Then 빌드 실패 + "점수
  누락" 메시지. Given 전 필수 필드 충족 + 태그 없음 / Then 발행 완료.
  Given 미등록 태그 표기 / Then 경고 산출, 발행은 진행.

### SS-2. 앨범 메타데이터 해석 `[CF-9 · US-10 · B6]`

- **트리거:** 새 앨범이 처음 참조될 때 (평론 발행 또는 이야기 참조).
- **규칙:** MusicBrainz 조회로 발매일·레이블 등 자동 채움 → 실패 시 User
  수기 입력 폴백. 조회는 **편집 시점에만** 발생, 배포 사이트에는 API 호출
  없음 (John 확인 사항). 발매 **연도**는 리스트 귀속에 필수 (SS-5).
- **예외:** MB 미등재 (비서구·소규모 인디) → 수기. 신보 반영 지연(B6 경고)
  → 수기 우선 입력 후 추후 MB ID 연결 허용.
- **인수조건:** Given MB 적중 / Then 원 입력 없이 메타 완성. Given MB 실패 +
  수기 없음 / Then 빌드 실패 + 누락 필드 명시 (발매 연도 없는 앨범은
  리스트 귀속 불능이므로).

### SS-3. 점수 규칙과 동점 처리 `[CF-1·2·3 · US-12 · D2·D4]`

- **규칙:** 점수는 0.0~10.0, 소수 1자리 고정. 모든 점수 정렬은 내림차순.
  동점 시 2차 키 = 평론 발행일 오름차순(이른 쪽 우선).
- **상태 전이:** 점수 수정 → 파생 리스트(보드·진행형 10선·월말정산) 전부
  재도출. 단 확정 스냅샷(SS-6)은 불변.
- **예외:** 소수 2자리 이상 또는 범위 밖 → 검증 실패 (SS-1). 보드 5위권
  경계의 동점 → 빌드가 알림 산출(원에게 전달용) + 기본 규칙으로 처리 진행
  (빌드를 막지 않는다).
- **인수조건:** Given 8.30 입력 / Then 실패. Given 동점 두 앨범 / Then 발행일
  이른 쪽이 상위 + 알림 파일 생성.

## 리스트 도출 계층

### SS-4. 장르 노미네이트 보드 도출 `[CF-3 · US-2 · D4]`

- **트리거:** 매 빌드.
- **규칙:** 버킷별(당해 설정 목록, "그 외" 제외) 당해 발매작 평론 중 점수
  상위 5 = 노미네이트. 1위 = 현재 선두. 평론 5편 미만이면 있는 만큼만.
- **상태 전이:** 새 평론/점수 수정으로 5위 경계가 바뀌면 보드 진입·탈락이
  자동 발생. 탈락 앨범의 평론·배지 상태도 갱신 (평론 페이지의 "현재
  노미네이트" 배지는 보드 상태의 파생물).
- **예외:** "그 외" 버킷 앨범 → 보드 대상 아님 (10선 후보는 유지, SS-5).
- **인수조건:** Given 힙합/R&B 평론 7편 / Then 보드에 상위 5만, 각 항목
  평론 링크 보유. Given 6위로 밀린 앨범 / Then 보드에서 제외 + 배지 제거.

### SS-5. 연간 10선 도출 `[CF-2 · US-1 · D3]`

- **트리거:** 매 빌드 (확정 전까지 진행형).
- **규칙:** 당해 **발매** 앨범의 평론 전체("그 외" 포함)에서 점수 상위 10.
  버킷 노미네이트 여부 무관. 동점 처리는 SS-3.
- **예외:** 당해 발매가 아닌 앨범(구반 평론) → 후보 제외, 아카이브에만.
- **인수조건:** Given "그 외" 버킷 9.1점 앨범 / Then 10선 후보에 포함.
  Given 2025년 발매 앨범의 2026년 평론 / Then 2026년 10선 후보 아님.

### SS-6. 연말 확정 전환 `[CF-2·3 · US-13 · D5]`

- **트리거:** 원의 확정 선언 + 서문 (시점은 원이 정함 — 시스템이 강제하지 않음).
- **상태 전이:** `진행형(보드·10선) → 확정 스냅샷` — 확정 시점의 순위·점수·
  노미네이트를 동결 저장 + 서문 결합 → "○○년 올해의 앨범" 확정 지면 공개
  → 이듬해 보드는 빈 상태로 리셋. 홈의 얼굴이 "확정 리스트 + 새해 빈 보드"로 전환.
- **규칙:** 확정 스냅샷은 이후 어떤 점수 수정·추가 평론에도 불변 (리스트 =
  발표 시점의 선언). 연말 시점 평론 2편 이하 버킷은 그 해 미발행 (D1 규칙,
  설정으로 변경 가능).
- **인수조건:** Given 확정 후 점수 수정 / Then 스냅샷 순위 불변 + 아카이브만
  갱신. Given 확정 후 지난해 발매작 평론 발행 / Then 스냅샷 불변.

### SS-7. 월말정산 생성 `[CF-4 · US-5]`

- **트리거:** 월 경계를 지난 첫 빌드.
- **규칙:** 해당 월 **발행** 평론(발매 연도 무관 — 그 달 매거진의 결산이므로
  구반 평론도 포함)을 점수순으로 묶은 페이지 생성. 항목 전부 평론 링크.
- **예외:** 해당 월 평론 0편 → 페이지 미생성, 월 목록에서도 제외 (빈 달을
  사과하는 지면을 만들지 않는다 — 빈도 무목표 원칙).
- **인수조건:** Given 9월 평론 3편 / Then "9월 정산" 페이지에 3편 점수순.
  Given 10월 평론 0편 / Then 10월 페이지 부재.

## 무결성 계층

### SS-8. 리스트-평론 연결률 100% 빌드 검사 `[USP-A · US-1·2·5 · Caleb §6-1]`

- **트리거:** 매 빌드.
- **규칙:** 모든 리스트 지면(보드·10선·월말정산·확정 스냅샷)의 전 항목이
  실존 평론 페이지로 해석되는지 검사. 하나라도 실패 → **빌드 실패** (경고
  아님). 추가로 내부 링크 깨짐·고아 콘텐츠(어느 탐색 축에도 없는 글) 검사.
- **주:** 리스트가 도출물이므로 이 검사는 이중 안전장치다 — 그래도 둔다
  (스냅샷·수기 편집 경로의 회귀 방지).
- **인수조건:** Given 평론 파일이 삭제된 스냅샷 항목 / When 빌드 / Then 실패
  + 해당 항목 명시.

## 연결 계층 (이해의 사다리)

### SS-9. 앨범 참조 해석 — 이야기 → 평론 `[CF-5 · US-4·11]`

- **트리거:** 음악 이야기 발행 및 매 빌드.
- **규칙:** 참조 앨범 목록의 각 항목을 앨범 데이터와 대조 — 평론 존재 시
  링크 생성, 부재 시 플레인 텍스트. **평론이 나중에 발행되면 다음 빌드에서
  소급 링크** (원의 옛 글 수정 불요). 참조에 선도/추종 역할 태그(옵션)
  보존 — 계보 시안 확정 시 시각 층이 소비 (소재는 "장르의 역사와 유행"으로
  구체화됨 — D9).
- **예외:** 참조 목록의 앨범명이 어느 데이터와도 불일치 → 빌드 경고 (오타
  탐지), 실패는 아님.
- **인수조건:** Given 참조 3개 중 평론 2개 존재 / Then 2개 링크 + 1개
  텍스트. Given 그 1개의 평론이 이후 발행 / Then 다음 빌드에서 3개 링크.

### SS-10. 역링크 — 평론 → 이야기 `[CF-5 · US-3]`

- **트리거:** 매 빌드.
- **규칙 (v1.1 폴백 사슬):** 앨범 X의 평론 페이지에 "이 앨범이 등장하는
  이야기"를 다음 우선순위로 구성 —
  ① X를 **직접 참조**하는 음악 이야기 전체 (발행일 역순)
  ② 0편이면 X의 **세부 장르 태그와 교집합**이 있는 음악 이야기
  ③ 그것도 0편이면 X의 **버킷과 일치**하는 음악 이야기
  ④ 전부 0편이면 영역 미표시.
- **인수조건:** US-3 AC1~3과 동일 (그쪽이 규범 — 폴백 순서 포함).
  Given 직접 참조 0 + 태그 일치 1 + 버킷 일치 3 / Then 태그 일치 1편만 표시.

## 탐색 계층

### SS-11. 아카이브 인덱스 생성 `[CF-7 · US-6]`

- **트리거:** 매 빌드.
- **규칙:** 연도(발행 기준) · 장르(버킷 기본, 세부 태그 보조 축) · 아티스트
  인덱스를 빌드 타임에 사전 계산 (John 검증: 30편 → ~120항목, 성능 무시
  수준). 전 글 유형 포함. 탐색 지면에는 점수 비표시 (D2).
- **인수조건:** Given 새 평론 발행 / Then 해당 연도·버킷·아티스트 인덱스에
  자동 편입 (+태그가 있으면 태그 인덱스에도). Given 어느 축에도 안 잡히는
  글 / Then SS-8 고아 검사에 걸림.

### SS-12. 아티스트 페이지 집계 `[CF-6 · US-9·14]`

- **트리거:** 아티스트가 처음 참조될 때 페이지 생성, 이후 매 빌드 갱신.
- **규칙:** 아티스트 페이지 = 소개글(있으면) + 그 아티스트 관련 전체 글
  자동 집계 (평론·참조된 이야기). 소개글과 집계는 순서 독립 (US-14 AC2).
  복수 아티스트 앨범은 각 아티스트 페이지에 모두 집계.
- **인수조건:** Given 소개글 없는 아티스트의 평론 2편 / Then 집계만으로
  페이지 성립, 빈 소개 영역 미표시.

## 부속 계층

### SS-13. 듣기 링크 생성 `[CF-10 · US-7]`

- **트리거:** 앨범 메타 확정 시 (SS-2 이후).
- **규칙:** 앨범 식별 정보로 스트리밍 아웃링크 자동 구성 (구체 서비스·방식은
  James 확정 — 검색형 링크 허용) + User 수기 오버라이드 우선.
- **예외:** 자동·수기 모두 부재 → 빌드 경고 (실패 아님 — 발행을 막지 않음).
- **인수조건:** Given 수기 링크 존재 / Then 자동 생성보다 우선 표시.
  Given 둘 다 없음 / Then 경고 산출 + 페이지는 링크 영역 미표시로 발행.

### SS-14. 커버 아트 처리 `[CF-1 · US-10]`

- **트리거:** 앨범 등록 시.
- **규칙:** 커버는 자체 호스팅 사본으로 저장·서빙 (John 권고: 외부 핫링크
  의존 금지, 지연 로드 + 폴백). 원에게 확보 책임을 지우지 않는다 (D7).
- **예외:** 커버 부재 → 플레이스홀더로 발행 가능 (빌드 경고).
- **의존:** 인용·비평 목적 사용의 법적 범위는 **James 소유 과제** (charter
  §6, task-graph 2.5). 그 결론이 이 스토리의 저장·표시 방식을 제약할 수
  있다 — **SS-15의 카드 이미지 사용 범위도 같은 결론에 묶인다.**
- **인수조건:** Given 커버 미확보 앨범 / Then 발행은 성공 + 경고 + 플레이스홀더.

### SS-15. 공유 메타(카드) 생성 `[CF-11 · US-15 · D8]` (v1.1 신규)

- **트리거:** 매 빌드, 전 공개 페이지.
- **규칙:** 페이지 유형별 카드 템플릿으로 OG 메타(제목·설명·이미지) 자동
  생성 — 평론: 커버·앨범·아티스트·매체명, **점수 비표시** (D2 — 점수를
  피드의 간판으로 만들지 않는다) / 리스트(월말정산·10선·보드): 리스트
  성격이 드러나는 구성 (점수 포함 여부는 Jonnathan 카드 시안에서 확정) /
  이야기·아티스트·기타: 제목 + 매체명 기본형. 원의 작업 0 — 링크만
  붙여넣으면 완성 (D8: 원의 SNS가 유입 축 ②의 실체).
- **예외:** 커버 부재 페이지 → 텍스트 기본형 카드로 폴백 (깨진 이미지 금지).
  커버의 카드 사용 가능 여부는 SS-14 법적 결론에 종속.
- **인수조건:** Given 임의 공개 페이지 / Then OG 메타 3요소가 존재하고
  유형별 템플릿과 일치한다. Given 평론 페이지의 카드 / Then 점수가 없다.
  Given 커버 없는 앨범의 평론 / Then 텍스트 기본형 카드로 생성된다.
